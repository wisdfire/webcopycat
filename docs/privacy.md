# WebCopyCat 개인정보처리방침

시행일: 2026년 10월 14일

## 수집하는 정보

WebCopyCat은 **어떠한 개인정보나 사용 데이터도 수집, 저장, 전송하지 않습니다.**

## 동작 방식

- 사용자가 툴바 아이콘, 우클릭 메뉴, 단축키로 직접 실행한 경우에만 현재 탭의 페이지 내용을 읽습니다.
- 읽은 본문 텍스트는 사용자의 기기 안에서만 처리되어 클립보드에 복사됩니다.
- 외부 서버로 네트워크 요청을 보내지 않으며, 분석·광고 도구를 사용하지 않습니다.

## 사용하는 권한

| 권한 | 사용 목적 |
|------|-----------|
| `activeTab` | 사용자가 실행한 탭에 한해 일시적으로 페이지 내용을 읽기 위함 |
| `scripting` | 본문 추출 스크립트를 해당 탭에 주입하기 위함 |
| `contextMenus` | 우클릭 메뉴에 "본문 복사" 항목을 추가하기 위함 |
| `offscreen`, `clipboardWrite` | 추출한 텍스트를 클립보드에 쓰기 위함 |
| `storage` | "제목 포함" 설정값(켜짐/꺼짐) 하나를 브라우저에 저장하기 위함. 개인정보는 저장하지 않음 |
