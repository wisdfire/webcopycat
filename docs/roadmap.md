# WebCopyCat 로드맵

## 개발 언어 및 환경

| 항목 | 선택 | 이유 |
|------|------|------|
| 플랫폼 | Chrome Extension **Manifest V3** | 웹스토어 신규 등록은 MV3만 허용 |
| 언어 | **JavaScript (ES2022)** + JSDoc 주석 | 파일 몇 개 규모라 TypeScript와 빌드 도구는 이득보다 부담이 큼. 필요해지면 나중에 전환 |
| 빌드 | **없음** | 폴더를 그대로 `압축해제된 확장 프로그램 로드` → 수정 후 새로고침만 하면 됨 |
| 본문 추출 | `@mozilla/readability` (파일 1개를 `lib/`에 그대로 복사해 사용, Apache-2.0) | 검증된 범용 본문 추출 엔진 |
| 테스트 | Playwright (개발용 의존성만) | 확장프로그램을 실제 Chromium에 로드해 복사 흐름 전체를 검증 |
| 에디터 | VS Code | — |
| 테스트 브라우저 | Chrome 최신 버전 | — |
| 배포 | Chrome Web Store 개발자 계정 (1회 등록비 US$5) | — |

## 1단계: MVP (핵심 복사 기능)

목표: 두 예시 사이트와 일반 블로그·뉴스에서 원클릭 본문 복사

- [x] `manifest.json` 작성 (권한: `activeTab`, `scripting`, `contextMenus`, `offscreen`, `clipboardWrite`)
- [x] `background.js`: 툴바 클릭, 우클릭 메뉴, 단축키를 하나의 `copyArticle(tab)` 함수로 연결
- [x] `content.js`: 사이트 규칙 → Readability 순서로 본문 추출, 텍스트 정리 후 반환
- [x] iframe 내부 본문 처리 (`allFrames: true`로 주입, 사이트 규칙 매칭 결과 우선 → 그다음 가장 긴 결과)
- [x] offscreen 문서로 클립보드에 쓰기
- [x] 성공/실패 배지 표시
- [x] 사이트 규칙: 넥슨 포럼 `.view-box .contents-box` (실제 페이지에서 확인)
- [ ] 사이트 규칙: 네이버 카페 `.se-main-container` (멤버 전용 글이라 로그인 상태에서 수동 확인 필요)
- [x] 자동 테스트: 픽스처(복사 방지 페이지), 넥슨 포럼, 위키백과, Chrome 문서
- [ ] 수동 테스트: 실제 Chrome에서 툴바/우클릭/단축키 3가지 실행 경로, 네이버 카페(로그인), 네이버 블로그, 티스토리

**완료 기준:** 예시 URL 2개에서 아이콘 클릭 시 패치 내용만 복사됨

## 2단계: 정확도 및 편의성

- [ ] 영역 선택 모드 (마우스를 올린 요소를 강조 표시하고 클릭하면 복사, `Esc`로 취소)
- [ ] 제목 포함 옵션 (`chrome.storage.sync`)
- [ ] 사이트 규칙 추가: 디시인사이드, 인벤, 루리웹, 아카라이브 등 게임 커뮤니티
- [x] 픽스처 기반 전체 흐름 테스트 (`npm test`, Playwright)

## 3단계: 스토어 등록

- [x] 아이콘 16/32/48/128px
- [x] 스크린샷 1280×800 1~5장, 짧은 설명(132자 이내), 상세 설명
- [x] 개인정보처리방침 페이지 ("수집하는 데이터 없음", GitHub Pages 등에 게시)
- [x] 단일 목적 설명과 권한별 사용 사유 작성
- [ ] `npm run zip`으로 패키징해 업로드 → 심사 (보통 수일 소요)
