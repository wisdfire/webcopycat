## 기본 정보

- **이름:** WebCopyCat - 게시물 본문 원클릭 복사
- **카테고리:** 생산성 (Productivity)
- **언어:** 한국어

## 간단한 설명 (132자 이내, manifest의 description과 동일)

클릭 한 번으로 게시물 본문만 텍스트로 복사합니다. 메뉴·댓글·광고 없이 본문만.

## 상세 설명

```
전체 선택(Ctrl+A)으로 복사하면 메뉴, 사이드바, 댓글까지 딸려 오고,
긴 글을 드래그로 고르기는 번거로우셨죠?

WebCopyCat은 페이지에서 게시물 본문을 자동으로 찾아
클릭 한 번으로 깔끔한 텍스트만 클립보드에 넣어 줍니다.

■ 사용 방법
- 툴바의 WebCopyCat 아이콘 클릭
- 페이지에서 우클릭 → "본문 복사 (WebCopyCat)"
- 단축키 Alt+Shift+C (chrome://extensions/shortcuts 에서 변경 가능)

복사가 끝나면 아이콘에 ✓ 표시가 잠깐 나타납니다.

■ 특징
- 게임 공식 포럼, 카페, 블로그, 뉴스 등 대부분의 사이트에서 본문 자동 인식
- 문단과 목록 줄바꿈을 유지한 일반 텍스트로 복사
- 개인정보 수집 없음, 외부 서버 통신 없음
- 오픈소스: https://github.com/wisdfire/webcopycat

■ 안내
복사한 콘텐츠는 개인적인 용도로만 사용해 주세요. 콘텐츠의 저작권은 원저작자에게 있습니다.
```

## 개인정보 보호 탭

- **단일 목적:** 사용자가 보고 있는 웹페이지에서 게시물 본문 텍스트를 추출해 클립보드에 복사합니다.
- **권한별 사유**
  - `activeTab`: 사용자가 아이콘, 우클릭 메뉴, 단축키로 실행한 탭의 본문을 읽기 위해 사용합니다.
  - `scripting`: 본문 추출 스크립트를 실행한 탭에 주입하기 위해 사용합니다.
  - `contextMenus`: 우클릭 메뉴에 "본문 복사" 항목을 제공하기 위해 사용합니다.
  - `offscreen`: 서비스 워커에는 DOM이 없어, 클립보드에 쓰기 위한 숨김 문서를 만들 때 사용합니다.
  - `clipboardWrite`: 추출한 본문 텍스트를 클립보드에 쓰기 위해 사용합니다.
- **원격 코드 사용:** 아니요
- **데이터 사용:** 수집하는 데이터 없음 (모든 항목 체크 해제)
- **개인정보처리방침 URL:** https://github.com/wisdfire/webcopycat/blob/main/docs/privacy.md
